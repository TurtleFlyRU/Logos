# Inline + purge + async (v5)

**Статус:** ✅ завершён

## Вывод

Гипотеза подтверждена: inline + purge + async даёт ~29% сокращения gzip (12.7KB → 9.0KB). Цель 30% не достигнута с точностью до 138 байт (1%). Практически — оптимизация успешна. Lighthouse подтвердил: Performance 98→99, TBT 76→57ms (-26%).

Ключевые результаты:
- Inline CSS+JS в HTML: 46.9KB raw → 36.7KB raw (-22%)
- Dead CSS purge (FontAwesome только иконки): 24.6KB → 10.8KB (-56%)
- Jivo/Metrika async: страница не блокируется
- Итог: 9.0KB gzip (-29%), не хватило 138B до цели 30%

## Новые принципы для памяти
- Inline + purge + async — рабочий паттерн для ~30% сокращения трафика на лёгких страницах
- FontAwesome purge (только используемые иконки) — основной источник экономии CSS
- Async для сторонних скриптов (Jivo, Metrika) — обязательно, даёт выигрыш в TBT
