# Гипотеза: Оптимизация главной страницы shtampuem.ru

**ID:** exp_1778150420
**Дата:** 2026-05-07 13:40

## Формулировка
Минимизировать HTML, CSS, JS: удалить пробелы, комментарии, объединить CSS, вынести повторяющиеся паттерны

## Обоснование
Стандартная практика веб-оптимизации: минификация + inline + удаление мёртвого кода дают 30-50% сокращения без потери функциональности

## Метрики

## План
1. **measure_before** — Замерить вес исходных файлов. Ожидание: Точные размеры в байтах
2. **optimize_html** — Минимизировать HTML: удалить пробелы, лишние атрибуты, сократить class/id. Ожидание: HTML уменьшен на ≥20%
3. **optimize_css** — Минимизировать и объединить CSS: удалить дубликаты, сократить селекторы. Ожидание: CSS уменьшен на ≥30%
4. **optimize_js** — Минимизировать JS: удалить пробелы, комментарии. Ожидание: JS уменьшен на ≥20%
5. **measure_after** — Замерить вес оптимизированных файлов. Ожидание: Общий вес уменьшен на ≥30%
