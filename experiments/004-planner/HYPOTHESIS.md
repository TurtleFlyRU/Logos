# Эксперимент 004: Дискретный планировщик

## Гипотеза

Дискретный планировщик, выбирающий действия на основе expected utility (польза × вероятность успеха),
даст более осмысленные последовательности действий, чем прямая next-token генерация.

## Метрики

1. **Выбор действия**: планировщик выбирает релевантное действие из кандидатов в ≥80% тестов
2. **Ожидаемая польза**: assigned utility коррелирует с человеческой оценкой (r > 0.5)
3. **Время принятия решения**: < 200ms на одно действие

## План

1. `ActionSpace` — словарь доступных действий с функциями оценки utility
2. `Planner` — дерево решений: candidates → score → select
3. `Memory.integrate_planner()` — вызов из respond() для сложных запросов
4. Тест: 5 сценариев, сравнение выбора планировщика с человеческой оценкой
