# Research Pipeline — исследовательский цикл Эйдоса

## Архитектура

Каждый эксперимент — отдельная директория в `experiments/NNN-name/`:

```
experiments/
├── INDEX.md              # Сводка всех экспериментов: номер, статус, вывод
│
├── 001-memory-prototype/
│   ├── HYPOTHESIS.md     # Гипотеза: что проверяем, почему, ожидаемый результат
│   ├── protocol.log      # Протокол: что сделано, время, метрики
│   ├── src/              # Код эксперимента
│   ├── results/          # Результаты (в .gitignore)
│   └── README.md         # Вывод: подтверждено/опровергнуто, что дальше
│
└── ...
```

## Цикл

1. **Гипотеза** → `HYPOTHESIS.md`
   - Формулировка
   - Обоснование (почему это может сработать)
   - Ожидаемый результат
   - Метрики успеха
   - Связанные принципы из семантической памяти

2. **План** → запись в Journal + `HYPOTHESIS.md` (раздел Method)
   - Шаги
   - Зависимости (библиотеки, модели)
   - Критерий остановки

3. **Эксперимент** → `runner.sh`
   - Установка зависимостей
   - Запуск кода
   - Замер метрик
   - Запись в `protocol.log`

4. **Протокол** → `protocol.log`
   - Что реально произошло
   - Метрики до/после
   - Неожиданности, ошибки
   - Ссылки на сгенерированные артефакты

5. **Вывод** → `README.md` + обновление `INDEX.md`
   - Подтверждена/опровергнута гипотеза?
   - Новые принципы для семантической памяти
   - Следующая гипотеза

6. **Интеграция** → sleep
   - Протокол → эпизодическая память
   - Вывод → семантическая память (принципы)
   - Оценка через Ethics Engine
