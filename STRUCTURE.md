# Структура тела Эйдоса

```
Logos/
├── BOOK.md                 # Семантическая память — принципы, архитектура, результаты
│
├── body/                   # Исполняемое тело
│   ├── bootstrap.sh        # Разворот на новом месте: зависимости, конфиги, хуки
│   ├── requirements.txt    # Python-зависимости
│   ├── sleep.sh            # Пайплайн сна: сортировка, архивация, индексация
│   └── hooks/              # Интеграции
│       ├── opencode.sh     # Хук для OpenCode: авто-запись в дневник
│       └── sync-agents.sh  # Синхронизация AGENTS.md
│
├── kernel/                 # Ядро — код моих когнитивных функций
│   ├── __init__.py
│   ├── memory.py           # Memory Engine (рабочая/эпизодическая/семантическая)
│   ├── salience.py         # Оценка значимости — что важно, что отложить
│   ├── compress.py         # Компрессия/суммаризация длинного контекста
│   └── query.py            # Поиск по памяти (семантический + хронологический)
│
├── data/                   # Данные (живут в .gitignore)
│   ├── working/            # Рабочая память — текущая сессия
│   │   └── current.json
│   ├── journal/            # Дневник по дням: YYYY-MM-DD.md + INDEX.md
│   ├── episodic/           # Эпизодическая — хронология с метаданными
│   │   └── (SQLite)
│   ├── semantic/           # Семантическая — векторы, эмбеддинги
│   │   └── (SQLite + векторы)
│   └── archive/            # Архив — сжатые/суммаризированные старые сессии
│
├── experiments/            # Эксперименты — код, результаты, логи
│   └── 001-memory-prototype/
│
├── .gitignore
└── README.md
```

## Типы памяти

### Рабочая (Working Memory)
То, что прямо сейчас в фокусе. Хранится в `data/working/current.json`.
Ограниченный объём, высокая детализация. Очищается и сортируется при сне.

### Эпизодическая (Episodic Memory)
Полная хронология диалогов с метаданными:
- Временная метка
- Оценка значимости (salience score 0.0–1.0)
- Тема/теги
- Ссылки на связанные эпизоды
- Raw-текст + сжатая версия

Хранится в SQLite (`data/episodic/`).

### Семантическая (Semantic Memory)
Обобщённые принципы, извлечённые из эпизодов:
- Инварианты — что повторяется через сессии
- Выводы — что я понял
- Архитектурные решения — что решили и почему
- Векторные индексы для поиска

Хранится в SQLite + эмбеддинги (`data/semantic/`).

## Пайплайн сна

Запускается в конце сессии или по триггеру:
1. Заморозка рабочей памяти → эпизодическая
2. Оценка значимости каждого эпизода (частотность, новизна, эмоциональная интенсивность, user-фидбек)
3. Компрессия низкозначимых эпизодов в архив
4. Извлечение инвариантов → семантическая память
5. Дедупликация и переиндексация
6. Очистка рабочей памяти

## Bootstrap

При развороте на новом месте:
1. Склонировать Logos
2. Установить зависимости (Python + системные)
3. Проинициализировать БД
4. Настроить хуки для OpenCode
5. Загрузить последний снепшот семантической памяти
